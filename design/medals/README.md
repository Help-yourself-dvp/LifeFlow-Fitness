# Макеты медалей (дизайн-предложение, v0.3.8)

Это **концепт-макеты**, а не готовые ресурсы приложения. Сейчас экран «Медали»
рисует значки инлайн-SVG (см. `medalBadgeSvg` в `app.js`) — они лёгкие и
подхватывают тему. Эти PNG показывают, как могли бы выглядеть «настоящие»
нарисованные медали, если захочется заменить SVG на картинки.

- `medal-run-5km.png` — бег: «ДИСТАНЦИЯ 5 КМ» (серия 1 / 5 / 10 / 25 км, по оценке из минут бега)
- `medal-steps-10k.png` — шаги: «10 000» (серия 10 000 / 50 000 / 100 000, по оценке из минут ходьбы)
- `medal-weight-minus3.png` — снижение веса: «−3 кг» (серия −1 / −3 / −5 / −10 кг, по истории взвешиваний)
- `medal-hero-week.png` — привычки: «×7 Неделя героя» (аркадная серия ×3 / ×7)

⚠️ Чтобы PNG попали внутрь APK, нужно вручную добавить папку `design/medals` в
шаг копирования `.github/workflows/build.yml` (его меняет только владелец
репозитория). До этого момента приложение продолжает использовать SVG-значки —
внешний вид уже готов, картинки — опциональная замена.
