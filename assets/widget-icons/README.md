# Значки для виджетов

Сюда кладутся ваши нарисованные значки. Натив ищет файл по имени
показателя; если файла нет — рисует эмодзи, как раньше. Поэтому можно
добавлять значки по одному, ничего не сломается.

## Имена файлов (ровно такие, латиницей, в нижнем регистре)

| Файл           | Показатель                     |
|----------------|--------------------------------|
| `water.png`    | Вода                           |
| `food.png`     | Питание                        |
| `steps.png`    | Шаги                           |
| `activity.png` | Активность                     |
| `sleep.png`    | Сон                            |
| `weight.png`   | Вес                            |
| `courses.png`  | Витамины                       |
| `workout.png`  | Календарь тренировок           |
| `day-plan.png` | План дня                       |
| `day-mood.png` | Самочувствие                   |

Значки для кнопок (если нужны отдельные от показателя):

| Файл              | Кнопка                  |
|-------------------|-------------------------|
| `btn-water.png`   | «+250 мл»               |
| `btn-food.png`    | «Еда»                   |
| `btn-courses.png` | «Витамины»              |
| `gear.png`        | Шестерёнка настроек     |

## Требования к картинкам

- **Формат:** PNG с прозрачным фоном (не JPG — он не умеет прозрачность).
- **Размер:** 96 × 96 пикселей. Значок на экране ~11–16 dp, но запас нужен
  для экранов с высокой плотностью; больше 192 × 192 смысла нет.
- **Поле:** рисунок впритык к краям, без собственных полей — отступы
  расставляет виджет. Квадратный холст.
- **Цвет:** рисуйте **белым по прозрачному**, одной заливкой без теней и
  градиентов. Виджет сам перекрашивает значок в цвет показателя, и на
  светлой теме — в тёмный. Цветной PNG перекрасить нельзя, он останется
  как есть и на светлой подложке может стать невидимым.
  Если значок должен быть именно цветным и неизменным — назовите файл
  с суффиксом `-color`, например `water-color.png`: такие не перекрашиваются.
- **Толщина линий:** не тоньше 6 px при холсте 96 px, иначе в мелком
  размере линия пропадёт (на этом уже обожглись с рисованными иконками).

После добавления файлов их надо просто закоммитить в репозиторий — сборка
сама положит их в APK.

## Откуда брать значки: готовые библиотеки (рекомендуемый путь, 0.9.35)

Рисовать самому не обязательно и обычно хуже. Проверенные наборы уже
имеют ровную толщину линий, нулевые поля и прозрачность:

| Набор | Лицензия | Коммерческое использование | Атрибуция в интерфейсе |
|---|---|---|---|
| Material Symbols (Google) | Apache 2.0 | да | не требуется, «приветствуется» |
| Lucide | ISC (часть — MIT от Feather) | да | не требуется |
| Phosphor Icons | MIT | да | не требуется |
| Tabler, Heroicons, Bootstrap Icons | MIT | да | не требуется |

**Так можно выкладывать приложение в магазины.** Условия у всех
перечисленных наборов — «пермиссивные»: разрешено использовать, изменять
и распространять в составе продукта, в том числе платного.

Единственное реальное требование этих лицензий — **сохранить текст
лицензии** где-то в составе проекта (не на экране, а в файле). Для этого
в репозитории есть `THIRD_PARTY_LICENSES.md`: добавьте туда набор,
который использовали. Отдельная строка в интерфейсе не нужна.

Чего избегать:
- **Font Awesome Free** и **CoreUI free** — лицензия CC BY 4.0, требует
  указания авторства;
- **Flaticon / The Noun Project** — бесплатно только с атрибуцией либо за
  деньги;
- Google просит **не перепродавать сами значки** отдельным товаром —
  использованию внутри приложения это не мешает.

### Как превратить SVG в наш PNG

1. Скачайте SVG (например, на lucide.dev или fonts.google.com/icons).
2. Экспортируйте в PNG 96 × 96, белым по прозрачному фону.
3. Назовите по таблице выше и положите в эту папку.

Векторный XML (`VectorDrawable`) в `res/drawable` — тоже рабочий путь для
Android, но наши виджеты рисуются на Canvas одной картинкой, поэтому
PNG проще: значок подхватывается без изменения кода.
