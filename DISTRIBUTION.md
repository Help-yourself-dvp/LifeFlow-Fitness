# Каналы распространения FitFlow — исследование (10.08.2026)

Подготовлено по запросу владельца. Статус каналов: **заморожено до отдельного
решения владельца** (см. ROADMAP.md → «💰 Монетизация»). Этот файл — справка
«что и сколько стоит», чтобы решение принималось по фактам.

## Действующий канал (сейчас)

- **GitHub Releases** — бесплатно, верификации личности нет (достаточно e-mail),
  автообновление отсутствует из коробки, зато его даёт Obtainium (ниже).
  Прямая ссылка на APK-последнего релиза — из README.

## Вариант: RuStore

Процедура для физлица (по материалам VK/пресс-релизам, 2022+):
VK ID → телефон и почта → **фото паспорта + селфи с лицом в камеру (биометрия)**
→ онлайн-проверка за несколько минут → модерация приложения. Монетизация —
только юрлицам; бесплатная публикация физлицу доступна, но верификация та же.
Источники: пресс-релиз VK от 16.09.2022 (vk.company/ru/press/releases/11269),
telesputnik.ru, new-retail.ru от 16.09.2022.

Вывод владельца (10.08.2026): объём персональных данных для бесплатной
публикации неприемлем — RuStore отложен до отдельного решения. К этому файлу
оно сторон этот вывод: паспорт и биометрия обязательны, «упрощённого пути» нет.

## Варианты без верификации личности

- **Obtainium** (open-source менеджер обновлений; поддерживает GitHub Releases
  и RuStore как источники) — пользователь добавляет ссылку на наш репозиторий,
  дальше приложение само следит за новыми APK и обновляет. Для нас это
  «магазин без магазина»: ничего публиковать не нужно, никаких наших данных.
  Сайт проекта: github.com/ImranR98/Obtainium. Это и есть ответ на вопрос
  «как распространять ссылку»: README + Obtainium закрывают автообновление
  без единой проверки личности.
- **F-Droid** — без аккаунта и верификации, но требует свободную (FOSS)
  лицензию и открытую сборку из исходников их фермой; наша лицензия
  (LICENSE, «личное использование, изменения без распространения») под FOSS
  не подпадает → не наш путь, если лицензия останется ограничительной.
- **Прямое распространение APK** мессенджерами/ссылкой — легально и уже
  работает; риск «левых» копий закрыт нашей LICENSE (п.2) и тем, что
  обновления всё равно ведут сюда.
- **4PDA** — точно нужна история/репутация аккаунта для создания тем
  (анти-спам), аудитория — техническая; не первый шаг.
- **Хабр-статья** — не канал-магазин, а история (офлайн-приватность, умный
  ввод); верификации личности нет, только e-mail. Заморожено вместе с каналами.

## Связанное новое требование экосистемы (на заметку)

С 2025–2026 Google движет «верификацию разработчиков» вне Play: для установки
приложений извне магазинов на сертифицированные устройства Google предлагает
разработчикам регистрировать package name в Android Developer Console
(типы Full ~$25 / Limited — бесплатно, до 20 устройств, без удостоверения
личности). На практике для нас: ничего делать не нужно, но если когда-нибудь
Android начнёт «ругаться» на установку APK извне — известен официальный
бесплатный контур (Limited Distribution). Источник: собственная справка
RuStore для разработчиков (rustore.ru/help/.../package-name-verification).
