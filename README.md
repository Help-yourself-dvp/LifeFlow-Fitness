# LifeFlow-Fitness — FitFlow (фитнес-трекер)

Мобильное приложение на базе **Capacitor/WebView** (Android), offline-first, без обязательной регистрации.
Все данные хранятся локально на устройстве.

> Репозиторий объединяет два будущих приложения: **FitFlow** (фитнес-трекер) и **LifeOps** (универсальный помощник).
> Сейчас в разработке — **FitFlow**.

## Текущий этап

- [x] Базовая структура: `index.html`, `style.css`, `app.js`
- [x] Система тем: Авто / Светлая / Тёмная (Material 3, авто-детект системы, сохранение выбора)

## Как смотреть приложение в браузере (без установки APK)

Приложение — это обычные HTML/CSS/JS, поэтому оно работает в любом браузере:

```bash
# 1) Просто открыть файл
open index.html          # macOS
xdg-open index.html      # Linux

# 2) Или поднять локальный сервер (рекомендуется)
npx serve .
# затем открыть http://localhost:3000
```

Готовые скриншоты интерфейса лежат в `previews/` — можно оценить дизайн без запуска.

## Структура

```
├── index.html      — разметка главного экрана и настроек
├── style.css       — Material 3 дизайн-система (light/dark токены)
├── app.js          — логика: темы, состояние, вода, парсер еды, экспорт/импорт, заглушка ИИ
├── test-parser.js  — автотесты парсера
├── previews/       — скриншоты интерфейса
└── (далее)         — package.json, capacitor.config.ts, workflow GitHub Actions
```

## Стек

- Чистые HTML/CSS/JS (без фреймворков — минимум зависимостей, быстро и надёжно в WebView)
- Material 3 (цветовые токены `--md-sys-color-*`)
- localStorage для хранения (позже — SQLite через Capacitor)
- Парсер текстового ввода еды с локальной базой ~190 продуктов (ккал на 100 г / на штуку)

## Заметки по ограничениям РФ

- ИИ-провайдеры (Gemini, DeepSeek, YandexGPT) подключаются **только по желанию пользователя**
  и как дополнение к локальному парсеру — приложение полноценно работает без них.
- Никаких обязательных регистраций и облачных аккаунтов.
- Ограничения бесплатных API (лимиты запросов/день) не критичны, т.к. ИИ не является
  обязательным путём выполнения основной логики.
