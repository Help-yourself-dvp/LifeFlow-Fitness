# Офлайн-справочник команд FitFlow

Этот справочник улучшает локальный быстрый и голосовой ввод без тяжёлой языковой модели.
Он не хранит данные пользователя и не требует Интернета.

## Что содержит справочник

1. **Ошибки распознавания речи**
   - `поплавов` → `плавал`;
   - `бана` → `банан`;
   - `грешка` → `гречка`;
   - `картошка` → `картофель`.

2. **Разговорные количества**
   - `два стакана` → 500 мл;
   - `пол литра` → 500 мл;
   - `полтора часа` → 90 минут;
   - `тарелка` → условная порция.

3. **Калорийные напитки**
   - чистая вода попадает только в трекер воды;
   - сок, компот, морс, квас, лимонад, смузи и другие напитки с калориями попадают в питание;
   - фраза `выпил 250 мл сока` распознаётся как питание, а не как вода.

4. **Типы активности**
   - бассейн / плавал → плавание;
   - бег / пробежка / кардио → кардио / бег;
   - силовая / тяжёлая атлетика → силовая;
   - прогулка → прогулка;
   - велосипед → велосипед;
   - растяжка / йога → растяжка.

## Принцип расширения

Добавляются короткие правила, синонимы и типичные ошибки, а не тысячи готовых
предложений. Сложные фразы всегда показываются пользователю для подтверждения.
В будущем локальная LLM станет fallback для неуверенно распознанных фраз.
